CalDAV

Synchroniseer je taken met elke app die CalDAV ondersteunt, zoals Apple Herinneringen, Thunderbird of DAVx⁵. Gebruik per apparaat een eigen app-wachtwoord. Taken verschijnen in de lijst Schrift.

Server-URL
https://schrift.example.com/caldav/
Gebruikersnaam
cas
App-wachtwoorden
iPhone Caslaatst gebruikt 8 minuten geleden
MacBooklaatst gebruikt gisteren

MCP-server

Geef een AI-assistent toegang tot je notities en taken. Clients met inloggen (OAuth), zoals claude.ai, koppel je via de server-URL. Andere clients, zoals Claude Code, gebruiken een token in de Authorization-header.

Server-URL
https://schrift.example.com/mcp
Tokens
Claude Code laptopaangemaakt 14 okt
Nieuw token: Claude Code server Kopieer het nu, het wordt hierna niet meer getoond. Voorbeeld voor Claude Code:
claude mcp add --transport http schrift https://schrift.example.com/mcp --header "Authorization: Bearer sk_schrift_[TOKEN]"
Gekoppelde clients
claude.ai (via inloggen)
